# ΕΚΦΩΝΗΣΗ

Για ποιες τιμές του $x \in \mathbb{R}$ η γραφική παράσταση της συνάρτησης $f$ βρίσκεται πάνω από τον άξονα $x'x$, όταν:

i) $f(x) = x^2 - 4x + 3$,
ii) $f(x) = \dfrac{1+x}{1-x}$,
iii) $f(x) = e^x - 1$.

## Υποερώτημα ii

ii) $f(x) = \dfrac{1+x}{1-x}$

## Λύση

Ομοίως έχουμε:
$$\dfrac{1+x}{1-x} > 0 \Leftrightarrow (1+x)(1-x) > 0 \Leftrightarrow 1-x^2 > 0 \Leftrightarrow x^2 < 1\Leftrightarrow \lvert x  \rvert < 1 \Leftrightarrow -1 < x < 1.$$
