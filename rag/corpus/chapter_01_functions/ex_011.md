# ΕΚΦΩΝΗΣΗ

Δίνονται οι συναρτήσεις $f(x) = x + 1$ και $g(x) = \alpha x + 2$. Για ποια τιμή του $\alpha \in \mathbb{R}$ ισχύει $f \circ g = g \circ f$.

## Λύση

Οι συναρτήσεις $f$ και $g$ έχουν πεδίο ορισμού το $\mathbb{R}$.

Για να ορίζεται η παράσταση $f(g(x))$ πρέπει:
$$ (x \in D_g \text{ και } g(x) \in D_f)\Leftrightarrow(x \in \mathbb{R} \text{ και } g(x) \in \mathbb{R}) \Leftrightarrow x \in \mathbb{R}.$$

Επομένως ορίζεται η $f \circ g$ με $D_{f \circ g } = \mathbb{R}$ και είναι
$$(f \circ g)(x) = f(g(x)) = f(\alpha x + 2) = \alpha x + 2 + 1 = \alpha x + 3.$$

Για να ορίζεται η παράσταση $g(f(x))$ πρέπει:

$$(x \in D_f \text{ και } f(x) \in D_g)\Leftrightarrow(x \in \mathbb{R} \text{ και } f(x) \in \mathbb{R}) \Leftrightarrow x \in \mathbb{R}$$.
Επομένως ορίζεται η $g \circ f$ με $D_{g \circ f } = \mathbb{R}$ και είναι
$$(g \circ f)(x) = g(f(x)) = g(x + 1) = \alpha(x + 1) + 2 = \alpha x + (\alpha + 2).$$

Θέλουμε να είναι $f \circ g = g \circ f$, που ισχύει μόνο όταν
$$(\alpha x + 3 = \alpha x + \alpha + 2, \text{ για κάθε } x \in \mathbb{R}) \Leftrightarrow \alpha + 2 = 3 \Leftrightarrow \alpha = 1.$$
