# ΕΚΦΩΝΗΣΗ

Δίνονται οι συναρτήσεις:
$$f(x) = \sqrt{x} + \dfrac{1}{\sqrt{x}} \quad \text{και} \quad g(x) = \sqrt{x} - \dfrac{1}{\sqrt{x}}.$$

Να βρείτε τις συναρτήσεις $f+g$, $f-g$, $fg$ και $\dfrac{f}{g}$.

## Λύση

Οι δύο συναρτήσεις έχουν κοινό πεδίο ορισμού το $A = (0, +\infty)$ (αφού πρέπει $x \geq 0$ λόγω της ρίζας στον αριθμητή και $\sqrt{x} \neq 0 \Leftrightarrow x \neq 0$ λόγω του παρονομαστή). Οπότε για κάθε $x \in A$ έχουμε:

$$(f+g)(x) = f(x) + g(x) = \left(\sqrt{x} + \dfrac{1}{\sqrt{x}}\right) + \left(\sqrt{x} - \dfrac{1}{\sqrt{x}}\right) = 2\sqrt{x}$$

$$(f-g)(x) = f(x) - g(x) = \left(\sqrt{x} + \dfrac{1}{\sqrt{x}}\right) - \left(\sqrt{x} - \dfrac{1}{\sqrt{x}}\right) = \dfrac{2}{\sqrt{x}}$$

$$(f \cdot g)(x) = f(x)g(x) = \left(\sqrt{x} + \dfrac{1}{\sqrt{x}}\right)\left(\sqrt{x} - \dfrac{1}{\sqrt{x}}\right) = (\sqrt{x})^2 - \left(\dfrac{1}{\sqrt{x}}\right)^2 = x - \dfrac{1}{x} = \dfrac{x^2 - 1}{x}.$$

Για την εύρεση της συνάρτησης $\dfrac{f}{g}$, πρέπει επιπλέον να ισχύει $g(x) \neq 0$.
Λύνουμε την εξίσωση $g(x) = 0$ για να βρούμε την τιμή που πρέπει να εξαιρεθεί από το κοινό πεδίο ορισμού $A$:
$$g(x) = 0 \Leftrightarrow \sqrt{x} - \dfrac{1}{\sqrt{x}} = 0 \Leftrightarrow \dfrac{(\sqrt{x})^2 - 1}{\sqrt{x}} = 0 \Leftrightarrow \dfrac{x - 1}{\sqrt{x}} = 0 \Leftrightarrow x - 1 = 0 \Leftrightarrow x = 1.$$

Επομένως, πρέπει $x \neq 1$. Άρα, το πεδίο ορισμού της $\dfrac{f}{g}$ είναι το $A' = (0, 1) \cup (1, +\infty)$.
Για κάθε $x \in A'$ ισχύει:
$$\left(\dfrac{f}{g}\right)(x) = \dfrac{f(x)}{g(x)} = \dfrac{\sqrt{x} + \dfrac{1}{\sqrt{x}}}{\sqrt{x} - \dfrac{1}{\sqrt{x}}} = \dfrac{\dfrac{(\sqrt{x})^2 + 1}{\sqrt{x}}}{\dfrac{(\sqrt{x})^2 - 1}{\sqrt{x}}} = \dfrac{\dfrac{x+1}{\sqrt{x}}}{\dfrac{x-1}{\sqrt{x}}} = \dfrac{x+1}{x-1}.$$
