# ΕΚΦΩΝΗΣΗ

Για ποιες τιμές του $x \in \mathbb{R}$ η γραφική παράσταση της συνάρτησης $f$ βρίσκεται πάνω από τη γραφική παράσταση της συνάρτησης $g$, όταν:

i) $f(x) = x^3 + 2x + 1$ και $g(x) = x + 1$
ii) $f(x) = x^3 + x - 2$ και $g(x) = x^2 + x - 2$.

## Υποερώτημα i

i) $f(x) = x^3 + 2x + 1$ και $g(x) = x + 1$

## Λύση

Η γραφική παράσταση της $f$ βρίσκεται πάνω από τη γραφική παράσταση της $g$ για εκείνα τα $x \in \mathbb{R}$ για τα οποία ισχύει
$$f(x) > g(x) \Leftrightarrow x^3 + 2x + 1 > x + 1 \Leftrightarrow x^3 + x > 0 \Leftrightarrow x(x^2 + 1) > 0 \Leftrightarrow x > 0.$$
