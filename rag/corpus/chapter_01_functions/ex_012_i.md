# ΕΚΦΩΝΗΣΗ

Δίνονται οι συναρτήσεις:
$$f(x) = \dfrac{\alpha x + \beta}{x - \alpha}, \text{ με } \beta \neq -\alpha^2 \quad \text{και} \quad g(x) = x - 2\sqrt{x} + 1.$$

Να αποδείξετε ότι
i) $f(f(x)) = x$, για κάθε $x \in \mathbb{R} - \{\alpha\}$

ii) Να αποδείξετε ότι $g(g(x)) = x$, για κάθε $x \in [0, 1]$.

## Υποερώτημα α

i) Να αποδείξετε ότι $f(f(x)) = x$, για κάθε $x \in \mathbb{R} - \{\alpha\}$.

## Λύση

Για να ορίζεται η συνάρτηση $f(x) = \dfrac{\alpha x + \beta}{x - \alpha}$, πρέπει:
$$x - \alpha \neq 0 \Leftrightarrow x \neq \alpha$$
Άρα $$D_f = \mathbb{R} - \{\alpha\}$$.

Για να ορίζεται η συνάρτηση $f(f(x))$, πρέπει:
$$(x \in D_f \quad \text{και} \quad f(x) \in D_f) \Leftrightarrow  (x \neq \alpha \quad \text{και} \quad \dfrac{\alpha x + \beta}{x - \alpha} \neq \alpha)$$

Άρα
$$\dfrac{\alpha x + \beta}{x - \alpha} \neq \alpha \Leftrightarrow \alpha x + \beta \neq \alpha(x - \alpha) \Leftrightarrow \alpha x + \beta \neq \alpha x - \alpha^2 \Leftrightarrow \beta \neq -\alpha^2$$
Η σχέση $\beta \neq -\alpha^2$ ισχύει πάντοτε, καθώς δίνεται ως δεδομένο στην εκφώνηση της άσκησης. Επομένως, ο μόνος περιορισμός που παραμένει είναι το $x \neq \alpha$.
Άρα $D_{f \circ f} =  \mathbb{R} - \{\alpha\}$.

Συνεπώς:

$$f(f(x)) = \dfrac{\alpha f(x) + \beta}{f(x) - \alpha} = \dfrac{\alpha \left( \dfrac{\alpha x + \beta}{x - \alpha} \right) + \beta}{\dfrac{\alpha x + \beta}{x - \alpha} - \alpha}$$

Εκτελούμε τις πράξεις στον αριθμητή και τον παρονομαστή του σύνθετου κλάσματος:
$$f(f(x)) = \dfrac{\dfrac{\alpha^2 x + \alpha \beta}{x - \alpha} + \dfrac{\beta(x - \alpha)}{x - \alpha}}{\dfrac{\alpha x + \beta}{x - \alpha} - \dfrac{\alpha(x - \alpha)}{x - \alpha}} = \dfrac{\dfrac{\alpha^2 x + \alpha \beta + \beta x - \alpha \beta}{x - \alpha}}{\dfrac{\alpha x + \beta - \alpha x + \alpha^2}{x - \alpha}}$$

Απλοποιούμε τους όρους και παραλείπουμε τους κοινούς παρονομαστές:
$$f(f(x)) = \dfrac{\alpha^2 x + \beta x}{\beta + \alpha^2} = \dfrac{x(\alpha^2 + \beta)}{\alpha^2 + \beta}$$

Οπότε:
$$f(f(x)) = x$$

Άρα, δείξαμε ότι $f(f(x)) = x$ για κάθε $x \in \mathbb{R} - \{\alpha\}$.
